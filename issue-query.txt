## Remaining Blocker

The build fails with: `class file for java.lang.MatchException not found`

**Root cause:** The codebase uses Java 21 pattern matching switch on sealed types (200+ occurrences). The compiler requires `java.lang.MatchException` at compile time for exhaustiveness checking, but Android SDK's `android.jar` doesn't include this class (added in Java 16).

- Adding MatchException to android.jar (module system prevents java.lang classes in unnamed modules)
- Boot classpath configuration via AGP (not supported)
- Desugaring library (only works at runtime, not compile time)
- `--patch-module` flag (AGP uses Compiler API, not command-line javac)
